Cupcake Birthday Scrapbook Website

Open index.html in a browser. Keep the folder structure intact:
- index.html
- styles.css
- app.js
- images/roblox1.jpg
- images/roblox2.jpg
- images/roblox3.jpg
- images/baby.jpg
- music/lovers-rock.mp3

Music is bundled and does not autoplay. Press the music button once; it loops and continues across the eight scenes.

Navigation: bottom arrows/dots, keyboard Left/Right, Escape closes letter modals.

The website is intentionally built as eight separate full-screen scenes rather than one long scrolling page, with a handmade scrapbook visual system inspired by the supplied reference image.
